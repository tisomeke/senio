# US-05. Модерация учебных материалов

## User Story

Как администратор Senio, я хочу проверять загруженные студентами материалы и управлять их публикацией через административную панель, чтобы в общем каталоге находились корректные и соответствующие дисциплинам учебные материалы.

## Пользователь

Администратор Senio, имеющий доступ к административной панели сервиса.

## Основной сценарий

1. Администратор открывает административную панель Senio.

2. Переходит в раздел «Модерация материалов».

3. Сервис отображает список материалов, ожидающих проверки.

4. Администратор выбирает материал из списка.

5. Сервис открывает информацию о материале: название, тип, дисциплину, курс, семестр, описание и загруженный файл.

6. Администратор просматривает содержимое файла и проверяет корректность указанных данных.

7. На основании проверки администратор принимает решение о публикации материала.

**Ветвь А. Материал соответствует требованиям**

8. Администратор нажимает «Одобрить».

9. Сервис присваивает материалу статус «Опубликован».

10. Материал становится доступен студентам через поиск и каталог.

**Ветвь Б. Материал не соответствует требованиям**

8. Администратор нажимает «Отклонить».

9. Сервис присваивает материалу статус «Отклонён».

10. Материал не публикуется в общем каталоге.
