# US-05. Модерация учебных материалов

## User Story

Как администратор Senio, я хочу проверять загруженные студентами материалы и управлять их публикацией через административную панель, чтобы в общем каталоге находились корректные и соответствующие дисциплинам учебные материалы.

## Пользователь

Администратор Senio, имеющий доступ к административной панели сервиса.

## Основной сценарий

1. Администратор открывает административную панель Senio.

2. Переходит в раздел «Модерация материалов».

3. Сервис отображает список материалов, ожидающих проверки.

4. Администратор выбирает материал из списка.

5. Сервис открывает информацию о материале: название, тип, дисциплину, курс, семестр, описание и загруженный файл. Если автоматическая обработка выполнена, сервис также показывает предложенные системой данные, помеченные как предложения.

6. Администратор просматривает содержимое файла и проверяет корректность указанных данных.

7. При необходимости администратор исправляет предложенные системой данные и сохраняет изменения.

8. На основании проверки администратор принимает решение о публикации материала.

**Ветвь А. Материал соответствует требованиям**

9. Администратор нажимает «Одобрить».

10. Сервис присваивает материалу статус «Опубликован».

11. Материал становится доступен студентам через поиск и каталог.

**Ветвь Б. Материал не соответствует требованиям**

9. Администратор нажимает «Отклонить».

10. Сервис предлагает указать причину отклонения. Администратор вводит причину и подтверждает отклонение; без указания причины действие не завершается.

11. Сервис сохраняет причину и присваивает материалу статус «Отклонён».

12. Сервис уведомляет автора об отклонении материала с указанием причины.

13. Материал не публикуется в общем каталоге.
