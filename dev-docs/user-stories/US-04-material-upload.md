# US-04. Загрузка нового учебного материала

## User Story

Как студент, я хочу загружать учебные материалы в общий каталог Senio, чтобы делиться ими с другими студентами и помогать им в подготовке к занятиям и экзаменам.

## Пользователь

Студент, желающий поделиться учебным материалом.

## Основной сценарий

1. Студент нажимает кнопку «Добавить материал».

2. Сервис проверяет, авторизован ли пользователь.

**Ветвь А. Пользователь авторизован**

3. Сервис открывает форму добавления материала.

**Ветвь Б. Пользователь не авторизован**

3. Сервис показывает уведомление: «Чтобы добавить материал, войдите или зарегистрируйтесь».

4. Если у студента уже есть аккаунт, он выбирает «Войти» и проходит авторизацию.

5. Если аккаунта нет, студент выбирает «Зарегистрироваться» и проходит регистрацию.

6. После успешной авторизации сервис открывает форму добавления материала.

**Общий сценарий после авторизации**

7. Студент выбирает файл со своего устройства.

8. Указывает название, тип материала, дисциплину, курс и семестр.

9. При необходимости добавляет описание материала.

10. Нажимает кнопку «Отправить на модерацию».

11. Сервис проверяет заполнение обязательных полей и допустимость формата файла.

12. Если проверка пройдена, сервис сохраняет материал, связывает его с учётной записью студента и присваивает статус «На модерации».
