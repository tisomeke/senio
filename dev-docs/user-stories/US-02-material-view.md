# US-02. Просмотр найденного материала

## User Story

Как студент, я хочу ознакомиться с описанием, характеристиками и содержимым найденного материала, чтобы определить, подходит ли он для моей учебной задачи, прежде чем скачивать его.

## Пользователь

Студент, который нашёл интересующий учебный материал.

## Основной сценарий

1. Студент выбирает интересующий материал из результатов поиска.

2. Сервис открывает отдельную страницу выбранного материала.

3. Студент знакомится с названием, типом и описанием материала, а также информацией о его дисциплине, курсе и других доступных характеристиках.

4. Студент просматривает содержимое файла непосредственно на странице с помощью встроенного предпросмотра. Предпросмотр доступен для форматов DOC, DOCX, PDF, TXT, PPT, PPTX и JPG.

5. На основании полученной информации студент определяет, подходит ли материал для его учебной задачи.

6. Если материал подходит, студент может перейти к его скачиванию. В противном случае — вернуться к результатам поиска.

## Альтернативные сценарии

### Формат не поддерживает предпросмотр

1. Студент открывает материал в другом формате, для которого встроенный предпросмотр не поддерживается.

2. Сервис показывает сообщение «Для этого формата предпросмотр недоступен. Скачайте файл, чтобы открыть его на устройстве».

3. Метаданные материала и кнопка «Скачать» остаются доступны, если исходный файл доступен для скачивания.

### Предпросмотр не удалось загрузить

1. При отображении поддерживаемого формата произошла ошибка.

2. Сервис сообщает, что предпросмотр не удалось загрузить.

3. Студент может повторить попытку или скачать исходный файл, если он доступен.
