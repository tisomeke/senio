# US-01. Поиск учебных материалов

## User Story

Как студент, я хочу находить учебные материалы по названию и уточнять результаты по дисциплине и типу материала, чтобы быстрее подобрать материалы для подготовки к занятиям или экзамену.

## Пользователь

Студент, которому нужен учебный материал. 

## Основной сценарий

1. Студент вводит поисковый запрос.

2. При необходимости выбирает дисциплину, курс и тип материала.

3. Сервис показывает опубликованные материалы, соответствующие запросу и выбранным фильтрам.

4. Студент знакомится с названиями, дисциплинами и типами найденных материалов.

5. Студент выбирает подходящий материал и открывает его для подробного ознакомления.
