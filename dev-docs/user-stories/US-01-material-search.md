# US-01. Поиск учебных материалов

## User Story

Как студент, я хочу находить учебные материалы по названию и уточнять результаты по дисциплине и типу материала, чтобы быстрее подобрать материалы для подготовки к занятиям или экзамену.

## Пользователь

Студент, которому нужен учебный материал. 

## Основной сценарий

1. Студент вводит поисковый запрос по названию материала.

2. При необходимости выбирает дисциплину, курс и тип материала.

3. Сервис показывает только опубликованные материалы, соответствующие запросу и выбранным фильтрам.

4. Студент знакомится с названиями, дисциплинами и типами найденных материалов.

5. Студент выбирает подходящий материал и открывает его для подробного ознакомления.

6. При просмотре каталога сервис показывает количество опубликованных материалов по дисциплинам. Для дисциплин без опубликованных материалов отображается отметка «Материалов пока нет».

## Альтернативные сценарии

### Ничего не найдено

1. По запросу и выбранным фильтрам нет опубликованных материалов.

2. Сервис показывает сообщение «Материалы не найдены».

3. Студент может изменить запрос, изменить или сбросить фильтры и повторить поиск.
