# US-08. Подача жалобы на материал

## User Story

Как пользователь, я хочу пожаловаться на опубликованный материал, если он содержит ошибки, не соответствует дисциплине или нарушает правила размещения, чтобы ответственные участники могли проверить его.

## Пользователь

Пользователь, обнаруживший проблему с опубликованным материалом. Требование авторизации для жалобы подлежит согласованию.

## Основной сценарий

1. Пользователь открывает страницу опубликованного материала.

2. Нажимает «Пожаловаться».

3. Сервис открывает форму жалобы.

4. Пользователь указывает причину и при необходимости добавляет пояснение.

5. Пользователь отправляет жалобу.

6. Сервис сохраняет жалобу со ссылкой на материал и подтверждает её получение.

7. Жалоба становится доступна ответственному за её рассмотрение участнику.

## Альтернативные сценарии

- Если причина не указана, сервис просит заполнить её.
- При ошибке отправки сервис сообщает, что жалоба не отправлена, и предлагает повторить попытку.
