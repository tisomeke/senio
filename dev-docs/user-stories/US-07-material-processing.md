# US-07. Интеллектуальная обработка учебных материалов

## User Story

Как модератор, я хочу получать автоматически извлечённый текст, предполагаемый тип материала, дисциплину, темы и краткое описание, чтобы быстрее проверять и классифицировать загруженные материалы.

## Пользователь

Модератор или администратор, проверяющий материалы.

## Основной сценарий

1. После успешной загрузки и технической проверки материала сервис запускает интеллектуальную обработку, если эта возможность включена.

2. Сервис определяет, поддерживается ли извлечение текста из формата документа.

3. Из поддерживаемого документа извлекается текст.

4. На основе извлечённого содержимого сервис предлагает тип материала, дисциплину, темы и краткое описание.

5. Результаты обработки сохраняются отдельно от исходных данных, введённых автором, и помечаются как предложения системы.

6. Подготовленные предложения сохраняются для последующей проверки человеком. Решение о публикации материала не изменяется автоматически.

## Альтернативные сценарии

- Если формат не поддерживается или текст не извлечён, сервис фиксирует причину и не создаёт вымышленные результаты.
- Если интеллектуальный сервис недоступен, фиксируется ошибка обработки; исходный файл и данные автора сохраняются.
- Если содержимого недостаточно для определения дисциплины или других сведений, соответствующее предложение не формируется.
