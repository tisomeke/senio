# US-11. ИИ-ассистент по учебным материалам

## User Story

Как студент, я хочу задавать вопросы по материалам выбранной дисциплины и получать ответы, основанные на опубликованных источниках Senio, чтобы быстрее разбираться в учебных темах.

## Пользователь

Студент, изучающий материалы выбранной дисциплины.

## Основной сценарий

1. Студент выбирает дисциплину и открывает ИИ-ассистента.

2. Вводит вопрос по учебным материалам.

3. Сервис находит подходящее содержимое опубликованных материалов этой дисциплины.

4. Ассистент формирует ответ с опорой на найденные источники.

5. Студент получает ответ и ссылки на использованные материалы.

## Альтернативные сценарии

- Если подходящих источников нет или их недостаточно, сервис сообщает об этом.
- Если ИИ-сервис недоступен, сервис показывает ошибку и предлагает повторить попытку.
