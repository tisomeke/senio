# US-12. Создание краткого содержания материала

## User Story

Как студент, я хочу получать краткое содержание выбранного учебного материала, чтобы быстрее знакомиться с его содержанием и повторять основные темы.

## Пользователь

Студент, открывший опубликованный учебный материал.

## Основной сценарий

1. Студент открывает страницу опубликованного материала.

2. Выбирает создание краткого содержания.

3. Сервис получает извлекаемое текстовое содержимое документа.

4. Сервис формирует краткое изложение основных положений.

5. Студент просматривает краткое содержание и может открыть исходный материал.

## Альтернативные сценарии

- Если формат не поддерживается или извлечённого текста недостаточно, сервис объясняет, почему краткое содержание недоступно.
- Если обработка завершилась ошибкой, сервис сообщает об этом и предлагает повторить попытку.
