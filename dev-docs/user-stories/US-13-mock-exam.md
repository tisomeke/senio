# US-13. Генерация пробного экзамена (Mock Exam)

## User Story

Как студент, я хочу сформировать и пройти пробный экзамен по выбранной дисциплине на основе опубликованных учебных материалов, чтобы оценить свою готовность к настоящему экзамену.

## Пользователь

Студент, готовящийся к экзамену по выбранной дисциплине.

## Основной сценарий

1. Студент выбирает дисциплину и запускает создание пробного экзамена.

2. Сервис выбирает опубликованные материалы этой дисциплины, пригодные для анализа.

3. Сервис получает текстовое содержимое поддерживаемых документов. Файлы, из которых не удалось получить пригодный для анализа текст, не используются для генерации.

4. На основе содержимого сервис формирует набор экзаменационных заданий.

5. Студент проходит пробный экзамен и отправляет ответы.

6. Сервис показывает результат, правильные ответы, объяснения и ссылки на соответствующие исходные материалы.

## Альтернативные сценарии

### Недостаточно исходных данных

Если опубликованных материалов или пригодного для анализа текста недостаточно, сервис объясняет, что сформировать экзамен пока невозможно.

### Ошибка извлечения текста или генерации

Сервис сообщает, на каком этапе не удалось подготовить экзамен, и предлагает повторить попытку. Неудачная генерация не отображается как готовый экзамен.
