# US-03. Скачивание учебного материала

## User Story

Как студент, я хочу скачивать найденные учебные материалы на своё устройство, чтобы иметь к ним доступ без интернета и использовать для подготовки к занятиям или экзаменам.

## Пользователь

Студент, который нашёл подходящий учебный материал. 

## Основной сценарий

1. Студент открывает страницу найденного материала.

2. При необходимости знакомится с описанием и содержимым файла с помощью предпросмотра.

3. Нажимает кнопку «Скачать».

4. Сервис предоставляет исходный файл для скачивания.

5. Браузер начинает загрузку файла на устройство пользователя.
