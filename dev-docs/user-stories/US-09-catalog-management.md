# US-09. Управление структурой каталога

## User Story

Как администратор, я хочу создавать и редактировать образовательные программы, курсы и дисциплины, чтобы поддерживать актуальную структуру библиотеки.

## Пользователь

Администратор Senio с правом управления каталогом.

## Основной сценарий

1. Администратор открывает раздел управления каталогом.

2. Выбирает образовательную программу или создаёт новую.

3. Добавляет или редактирует относящиеся к ней элементы учебной структуры, включая курсы и дисциплины.

4. Сервис проверяет обязательные данные.

5. Администратор сохраняет изменения.

6. Сервис обновляет структуру, доступную при поиске и загрузке материалов.

## Альтернативные сценарии

- При незаполненных обязательных полях сервис указывает ошибки.
- При ошибке сохранения сервис сообщает, что изменения не применены.
- Пользователь без соответствующего права не может изменять структуру каталога.
