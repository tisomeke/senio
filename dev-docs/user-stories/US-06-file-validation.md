# US-06. Автоматическая проверка загружаемых файлов

## User Story

Как система, я хочу автоматически проверять загружаемые файлы на соответствие техническим требованиям и возможность обработки, чтобы не передавать на дальнейшую проверку заведомо некорректные материалы.

## Пользователь

Сервис Senio, выполняющий автоматическую техническую проверку загружаемого файла.

## Основной сценарий

1. Авторизованный студент отправляет форму загрузки по US-04.

2. Сервис проверяет обязательные поля и подтверждение права на распространение.

3. Сервис проверяет, что размер файла не превышает 20 МиБ (20 971 520 байт).

4. Сервис проверяет соответствие фактического формата разрешённому перечню: DOC, DOCX, PDF, TXT, PPT, PPTX, JPG. Имя файла и MIME-тип от клиента не являются единственным основанием проверки.

5. Если обязательные проверки пройдены, сервис продолжает сохранение и отправку материала по US-04.

6. Если проверка обнаруживает нарушение, сервис прекращает отправку и сообщает студенту причину.

## Альтернативные сценарии

### Недопустимый файл

Сервис отклоняет файл, превышающий лимит или не соответствующий допустимому формату, и предлагает выбрать другой файл.

### Проверку не удалось завершить

Сервис сообщает о технической ошибке и возможности повторить отправку. Непроверенный файл не считается успешно прошедшим проверку.
