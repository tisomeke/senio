# US-10. Генерация проверочных заданий

## User Story

Как студент, я хочу генерировать тесты по выбранной дисциплине на основе опубликованных учебных материалов, чтобы проверять свои знания.

## Пользователь

Студент, желающий проверить знания по дисциплине.

## Основной сценарий

1. Студент выбирает дисциплину и запускает генерацию проверочных заданий.

2. Сервис выбирает опубликованные материалы с доступным для анализа содержимым.

3. Сервис формирует вопросы с вариантами ответов на основе выбранных источников.

4. Студент отвечает на вопросы.

5. Сервис показывает результат, правильные ответы, объяснения и ссылки на использованные материалы.

## Альтернативные сценарии

- Если подходящих материалов или извлечённого текста недостаточно, сервис объясняет, почему генерация недоступна.
- При ошибке генерации сервис сообщает о неудачной попытке и возможности повторить запрос.
