# Документация Senio

Карта документации и источников истины. Здесь только навигация:
содержимое живёт в указанных файлах.

## Карта документов

- `README.md` — вход для людей: описание проекта, стек, запуск.
- `AGENTS.md` — правила и подтверждённое состояние для ИИ-агентов.
- `docs/ROADMAP.md` — единственный живой план: MVP, порядок работ и
  открытые вопросы.
- `docs/annotation.md` — архивный снимок для жюри; не редактируется.
- `dev-docs/user-stories/` — пользовательские истории US-01–US-13 и
  карта `US-MOC.md`.
- `dev-docs/git-workflow.md` — правила веток, коммитов, Pull Request,
  ревью и Kanban.
- `docs/README.en.md` — заготовка английской версии README (WIP).
- `.agents/skills/` — Skill'и для ИИ-агентов.

## Как взять первую задачу

1. Выбери карточку в колонке Ready на доске
   [Kanban](https://github.com/users/tisomeke/projects/3) в GitHub
   Projects.
2. Назначь задачу на себя.
3. Перемести карточку в In progress.
4. Создай или возьми Issue по шаблону задачи либо микрофикса.
5. Создай отдельную ветку от актуальной `main`.
6. Открой PR и свяжи его с Issue через `Closes #N` или `Refs #N`.
7. Перемести карточку в In review; после слияния она перейдёт в Done.
