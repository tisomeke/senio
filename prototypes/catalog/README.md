# Senio — пошаговый выбор

## Локальный запуск

В VS Code откройте корень рабочей копии пошагового варианта (ветка `feature/57-catalog-prototype`). В нём рядом находятся папки `prototypes` и `static`.

- **В браузере.** В панели Explorer нажмите правой кнопкой на `prototypes/catalog/index.html`, выберите **Reveal in File Explorer** и дважды щёлкните [index.html](index.html) в проводнике. Можно также выбрать **Open in Integrated Browser**, если этот пункт доступен в VS Code.
- **Через Live Preview.** Если установлено расширение [Live Preview от Microsoft](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server), откройте `prototypes/catalog/index.html` в редакторе и нажмите кнопку предварительного просмотра в правом верхнем углу. Открывайте рабочую копию целиком, чтобы сервер расширения мог отдать логотип и изображения из `static/img/`.

На главной странице появится кнопка «Выбрать институт». Для запуска достаточно браузера и файлов репозитория. Tailwind CSS и веб-шрифты загружаются через интернет.

## Что попробовать

1. На главной ЮФУ нажмите «Выбрать институт». Выберите Институт математики и компьютерных наук, направление ФИИТ, первый курс и дисциплину «Дискретная математика».
2. Выберите первый семестр и посмотрите материалы. Нажмите «Назад» и выберите второй семестр — появится серый Сенька с сообщением «Материалов пока нет». Оба семестра доступны по учебному плану.
3. Вернитесь к дисциплинам через «1 курс» в хлебных крошках. Откройте «Основы программирования» — материалы первого семестра появятся сразу, поскольку у этой дисциплины на выбранном курсе всего один семестр.
4. Сравните «Языки программирования» на двух курсах ФИИТ. На первом курсе откроется пустой второй семестр. На втором курсе откроется третий семестр с материалами. Выберите тип «Лекция», чтобы увидеть «Системы типов».

Данные в [demo-data.js](demo-data.js) вымышлены и используются только для демонстрации.
