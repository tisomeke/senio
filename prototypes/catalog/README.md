# Senio — поиск и фильтры

## Локальный запуск

Откройте папку `prototypes/catalog` в локальной копии репозитория и дважды щёлкните [index.html](index.html). Устанавливать зависимости или запускать сервер не требуется. Браузер загружает Tailwind CSS и веб-шрифты через интернет.

## Как проверить поиск и фильтры

При открытии страницы и после очистки поиска и фильтров видны десять последних добавленных материалов, начиная с самого нового.

1. В строке «Найти материалы по дисциплине» введите «Языки программирования». Выдача обновляется по мере ввода. Появятся три материала с двух направлений. На карточках указаны тип материала, дисциплина, курс, семестр, направление и институт. Чтобы оставить только лекции, выберите «Лекция» в поле «Тип материала».
2. Очистите строку поиска. В фильтрах выберите ФИИТ, первый курс, первый семестр и «Дискретную математику». Нажмите «Результаты поиска» — появятся карточки материалов. Если оставить «Все дисциплины», выдача охватит все дисциплины выбранного семестра.
3. Откройте фильтры, нажмите «Сбросить» и закройте окно крестиком. Сброс действует сразу: счётчик исчезает, а на странице снова видны последние материалы. Если в строке был поисковый запрос, он сохранится и выдача обновится по нему.

Поля фильтров идут в порядке «Институт → Направление подготовки → Курс → Семестр → Дисциплина». Можно заполнить только нужные поля. При изменении одного поля все последующие очищаются, а их варианты пересчитываются по учебному плану. Поэтому семестр можно выбрать, даже если в нём ещё нет материалов.

Если поиск по названию или выбор типа материала не дал совпадений, появляется серый Сенька с сообщением «Материалы не найдены» и подсказкой, что изменить.

## Как увидеть серого Сеньку, когда материалов пока нет

1. На главной странице очистите строку поиска и нажмите значок фильтров справа от неё.
2. Выберите по порядку: «Институт математики и компьютерных наук» → «Фундаментальная информатика и информационные технологии (ФИИТ)» → «1 курс» → «2 семестр» → «Дискретная математика».
3. Нажмите «Результаты поиска». Появятся серый Сенька и сообщение «Материалов пока нет»: в учебном плане дисциплина есть в обоих семестрах первого курса, а материалы добавлены только в первом.

Данные в [demo-data.js](demo-data.js) вымышлены и используются только для демонстрации.
